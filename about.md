# A propos de Confiserie de Minuit : Sucreries Maudites

**Confiserie de Minuit : Sucreries Maudites** est un simulation de boutique magique developpe par **Geoffroy Streit** (alias **Hylst**).

## Le jeu
Simulation de boutique ensorcelée : concocte des friandises maudites en suivant les formules du grimoire, satisfais les clients VIP vampires et momies, et évite les faillites nocturnes.

## Le createur
- Developpeur d'applications, ancien graphiste et compositeur
- Adepte de retrocomputing et de demoscene
- Createur de la plateforme de jeux 100% front-end Hylst.Games

## Stack technique
- React 19 + TypeScript + Tailwind CSS 4
- Vite 7 + vite-plugin-singlefile
- 100% statique, sans serveur ni collecte de donnees
