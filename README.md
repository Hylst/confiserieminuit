# Confiserie de Minuit : Sucreries Maudites

**Servir les créatures sans se faire croquer**

Joue en ligne sur : [https://games.hylst.fr/confiserieminuit/](https://games.hylst.fr/confiserieminuit/)

## Description
Simulation de boutique ensorcelée : concocte des friandises maudites en suivant les formules du grimoire, satisfais les clients VIP vampires et momies, et évite les faillites nocturnes.

## Controles
| Contrôle | Action |
|---|---|
| Clic / Tap | Composer les plateaux de bonbons |
| Grimoire | Consulter les recettes et commander des stocks |

## Developpement
```bash
# Installer les dependances
npm install

# Lancer le serveur local
npm run dev

# Compiler pour la production (build single-file)
npm run build
```
